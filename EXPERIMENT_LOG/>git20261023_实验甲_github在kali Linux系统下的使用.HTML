模块一 · 环境配置

配置提交身份

git config --global user.name "Hannam1" git config --global user.email "2311347434@qq.com"
验证：git config --list 或 git config --global -l

生成 SSH 密钥（免密）

ssh-keygen -t ed25519 -C "2311347434@qq.com"
三个提示全部直接按回车：保存路径 → 密码 → 确认密码，都留空。

查看公钥 / 测试连接

cat ~/.ssh/id_ed25519.pub
ssh -T git@github.com
出现 Hi Hannam1VM! You've successfully authenticated 即成功。

设置默认分支名

git config --global init.defaultBranch main

模块二 · 本地仓库操作

完整初始化流程

mkdir -p ~/security-lab && cd ~/security-lab
echo "# 我的实验记录" > README.md
git init
git add . git commit -m "init: 实验记录仓库"
git remote add origin git@github.com:Hannam1VM/Security-labbb-Hannam1.git
git push -u origin main

日常三条命令

git add . git commit -m "描述这次做了什么" git push

状态与查看

git status # 看当前改动 git log --oneline # 看提交历史 git remote -v # 查看远程地址 git branch -M main # 把当前分支改名为 main

同步远程

git pull # 已关联分支时直接用 git pull origin main # 首次或未关联时用

模块三 · 上传与下载完整流程

场景 A：Kali 修改后上传 GitHub

出现 main -> main 即成功，网页刷新可见。

场景 B：网页改动后 Kali 同步

cd ~/security-lab git pull

场景 C：新机器完整克隆

git clone git@github.com:Hannam1VM/Security-labbb-Hannam1.git cd Security-labbb-Hannam1

场景 D：只下载单个文件

wget https://raw.githubusercontent.com/Hannam1VM/Security-labbb-Hannam1/main/README.md
raw 地址格式：raw.githubusercontent.com/用户名/仓库名/分支名/文件路径
